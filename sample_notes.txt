Machine Learning Lecture Notes - Week 4: Supervised Learning & Neural Networks

Machine learning is an application of artificial intelligence that provides systems the ability to automatically learn and improve from experience without being explicitly programmed. In traditional programming, humans write code that encodes logic and rules directly, which converts input data into desired output. In contrast, machine learning takes input data along with expected outputs to discover underlying patterns, algorithms, and statistical relationships.

Supervised learning is the most widely deployed category of machine learning in industry today. In supervised learning, models are trained using labeled datasets where each training example is paired with an output label. Common supervised tasks include regression, which predicts continuous numerical values like housing prices or stock market movements, and classification, which assigns inputs into discrete categories like email spam detection or medical disease diagnosis.

A central challenge in machine learning is the bias-variance tradeoff. Bias refers to error introduced by approximating a real-world problem with an overly simplistic model, which frequently leads to underfitting where the model fails to capture key relationships. Variance refers to the model's sensitivity to small fluctuations in the training dataset, which leads to overfitting where the model memorizes random noise rather than generalizing to unseen data. Regularization techniques like L1 lasso and L2 ridge penalties are widely utilized to constrain model complexity and mitigate overfitting.

Neural networks are computational models inspired by the biological neural structure of the human brain. An artificial neural network consists of interconnected nodes called artificial neurons organized into an input layer, one or more hidden layers, and an output layer. Each connection between neurons possesses an associated numeric weight that represents the strength of influence between those nodes. When a neuron receives inputs, it computes a weighted sum, adds a bias term, and passes the result through an activation function like Rectified Linear Unit (ReLU), Sigmoid, or Softmax to introduce non-linearity.

Training a neural network involves iteratively optimizing its weights using the backpropagation algorithm combined with gradient descent. During the forward pass, data flows through the network layers to produce a prediction, and a loss function measures the discrepancy between this prediction and the true ground-truth label. During the backward pass, the chain rule of calculus is applied to compute partial derivatives of the loss function with respect to every weight in the network. Optimization algorithms like Adam or Stochastic Gradient Descent then adjust the weights in the direction that minimizes total loss across epochs.

Model evaluation requires strictly partitioning the available data into training, validation, and test subsets. Practitioners must never evaluate final model performance on data seen during training or hyperparameter tuning, as this introduces severe data leakage and produces falsely optimistic accuracy estimates. In addition to accuracy, metrics such as precision, recall, and F1-score are critical when dealing with imbalanced datasets.
